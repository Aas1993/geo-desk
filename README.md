# Geo Desk

A dark, full-screen world map with a dossier for every country — UAE-centric, inspired by the DiploMaps concept (own name, own code, own data pipeline).

Design plan: [docs/design-plan.md](docs/design-plan.md).

```bash
npm install
node scripts/build-countries.mjs   # one-off: public/data/countries.json (World Bank + Wikidata)
node scripts/build-un.mjs          # one-off: UN voting data + HS chapter names (streams ~145 MB from Harvard Dataverse, ~35 s)
npm run dev                        # copies the MapLibre worker to /public, then starts Next on :3000
```

## What Phase 0–1 ships
- MapLibre globe, Natural Earth boundaries, country select/hover/outline, capitals, deep links (`?sel=ARE&tab=economy#zoom/lat/lng`).
- Country panel: Overview (capital, local time, weather, AQI, leaders, borders), Economy, Trade, Military (SIPRI via World Bank), Society, News.
- **Live layers** (layers drawer; URL-shareable): flights incl. military, natural hazards, outbreaks, weather and radar, NASA true-colour imagery, fires, satellites, launches, GDELT events, GPS interference, sanctions by country, and 59 membership layers (52 with a list) (UN, EU, NATO, GCC, OPEC, BRICS…). Every layer shows an honest status; sources and caveats are in `src/lib/layers/registry.ts`.
- **UAE agreements, flights and investment** (country panel → Agreements, plus map layers): treaties, MoUs, CEPAs with signed/in-force dates, tax and air treaties, joint economic committees and economic offices from MOFA and the Ministry of Foreign Trade; direct destinations and airlines from UAE airports (active vs suspended); UAE investment position by country from the IMF. A daily workflow (`.github/workflows/refresh-data.yml`) rebuilds agreements, flights, investment, missions, visits, IMF trade and outlook and then the Partnership Index, runs the tests, and opens (or updates) one standing PR when something really changed. A separate daily job rebuilds the media-tone data from GDELT's raw event files and a monthly job rebuilds the reference data. Ransomware, sanctions, the UN votes and the NPT/IAEA/ECOSOC lists are rebuilt by hand (`node scripts/build-*.mjs`) and are not scheduled. See `docs/parity.md` for what is and is not built against DiploMaps.
- **UAE Partnership Index** (Overview tab, layer, dashboard widget): a transparent 0-100 score per country from trade, diplomatic engagement, agreements and CEPA, flights and embassy, UAE investment and UN voting alignment, with every raw value shown. **Trade intelligence** (Trade tab): UAE goods trade with each partner (IMF, quarterly through 2026), share, rank, momentum and a **CEPA impact** readout (trade since entry into force against the UAE's overall trade); **IMF outlook** (Economy tab): growth, inflation, current account, debt and unemployment to 2028 with ranks, plus the **export-demand outlook** (partner-weighted growth) on the UAE's page. **Minister brief** (own tab): AI brief for a UAE minister about to meet or call the country, with a suggested opening, objectives, talking points, likely questions with suggested answers, sensitivities and open items, every point cited (`PREP_MODEL`, `PREP_MAX_PER_HOUR`, `PREP_ENABLED`).
- **Diplomacy** (country panel → Diplomacy, plus layers): the UAE's 124 embassies, consulates and permanent missions (plus 3 visa centres) with ambassador names and contacts (MOFA directory), and about 2,100 official visits, meetings, calls and signings since Nov 2024 from WAM headlines (auto-classified by rules; filter by seniority and direction).
- **Media radar** (country panel → Media): how a country's media cover the UAE (GDELT tone), think-tank pieces whose titles name the subject, and an opt-in AI stance read (hostile / critical / neutral / friendly / supportive per headline, with evidence). Social feeds are not shown: X, Telegram and others have no compliant free access.
- **Dashboard and Ask**: role presets, saved layouts, 20 widgets, watchlist, AI world brief, Ask (answers only from this app's data, with cited facts), one-page printable country brief.
- **Alerts bell**: one merged feed (hazards, WHO, GDELT, headlines) with UAE radar / everywhere / flagged / security tabs.
- Search (`/` or ⌘K), layers drawer, live headline ticker (RSS), EN/AR with RTL, light/dark, text size, mobile bottom sheet.
- Every figure shows its year and source; unavailable data shows an honest empty state.

## Gulf equities (ADX + DFM + Qatar) — `/markets`
- **Universe**: all 83 ADX, 56 DFM and 55 Qatar Stock Exchange (QSE, Boursa Qatar) listings (`node scripts/build-markets.mjs`; DFM tickers are validated against DFM's own disclosure feed, vendor aliases such as AIRA are dropped in favour of AIRARABIA).
- **Board**: sortable/filterable table with price, change, volume, 52-week range, 1W/1M/3M/YTD/1Y returns, RSI, distance from SMA200, 60-day volatility, sparkline, movers, advancers/decliners, CSV export.
- **Stock page** (`/markets/DFM/EMAAR`): interactive chart (line/candles, SMA 20/50/200, EMA, Bollinger, volume, RSI, MACD, crosshair), performance and risk, technical readings, pivot points, valuation / profitability / health / growth ratios, income statement, balance sheet and cash flow (annual & quarterly), dividend history, earnings vs estimates, and the company's **DFM disclosure timeline with PDF links**.
- **Data honesty**: ADX forbids automated retrieval and DFM's public feed carries disclosures only, so prices and fundamentals come from a licensed vendor (Twelve Data, which lists both exchanges). Put a key in `.env.local` (`TWELVEDATA_API_KEY`, see `.env.example`). Without one the pages still list every stock and show DFM filings, and say plainly that prices aren't connected. ADX filings are not shown (no compliant source).
- **Qatar (QSE)**: listings come from the vendor's reference list (symbols such as `AHCS@S` are dropped). Quoted in QAR, Sunday to Thursday 09:30 to 13:15 AST (continuous trading to 13:00, then the closing auction). There is no Qatar disclosure feed in the app: qe.com.qa asks robots not to read its documents, so `qe.com.qa` is also blocked for the AI research and briefing tools, which use other public sources instead. The Indices panel has the QE Index and USD/QAR as TradingView embeds (the `QSE:GNRI` symbol is unverified). Prices and fundamentals need a Twelve Data Pro key, as for ADX; none is set in this checkout, so the Qatar rows show the same "prices not connected" state as ADX and DFM.
- Indicator maths is dependency-free and tested (`npx tsx src/lib/markets/indicators.test.ts`, includes Wilder's textbook RSI). Vendor response mappers are checked against the vendor's demo payloads (`npx tsx scripts/verify-td-shapes.ts`).
- `GD_FIXTURES=1` (dev only) swaps in clearly-labelled synthetic data so the UI can be worked on without a key; it is ignored in production builds.

## Connecting prices (checklist)
0. **Plan note (checked 17 Oct 2026 via the vendor's `/exchanges?show_plan=true`)**: Twelve Data lists ADX and the Qatar Stock Exchange (code QE, MIC DSMD) on **Pro** and DFM on **Ultra**. Free/Basic keys do not cover either exchange.
1. Get a key on a plan that covers them and put it in `.env.local`: `TWELVEDATA_API_KEY=...` (and `TWELVEDATA_RPM=<credits per minute on your plan>`; free = 8).
2. `node scripts/verify-markets.mjs --limit=16` — quick smoke test (reads your plan, probes every dataset on ADCB and EMAAR, quotes 16 symbols per exchange).
3. `node scripts/verify-markets.mjs` — full check of all 139 listings. It retries vendor aliases (e.g. EMAR for EMAAR), writes `public/data/vendor-map.json` (alias fixes and "no vendor data" flags, read by the server) and `vendor-report.json`.
4. Restart `npm run dev`, open `/markets`, then a stock such as `/markets/DFM/EMAAR` and `/markets/ADX/ADCB`.
A batch of N symbols costs N credits; pacing follows `TWELVEDATA_RPM`. Fundamentals (statistics, statements) are usually paid-plan datasets; where your plan lacks one, that panel says so and the rest still works.

## AI research tab (stock pages → "AI research")
An AI analyst briefed as a senior GCC banker writes an initiation-style note on the selected stock: executive summary and research stance, snapshot and ownership, dated recent developments, financial position (multi-year table plus sector KPIs), **trading and liquidity including number of trades where the exchange publishes it**, valuation and dividends vs peers, technical context, catalysts, bull/base/bear scenarios, ranked risks and red flags, management questions, a data-gaps table and a numbered source list.
- **How it researches**: `src/lib/research/gather.ts` first collects verified facts (DFM's disclosure feed with PDF links, recent headlines, and licensed price data if connected), then Claude (`claude-sonnet-5-5`, effort medium, at most 8 searches and 4 page reads) browses with the server-side `web_search` and `web_fetch` tools, reading DFM filing PDFs and public sources. `adx.ae` is excluded (its terms prohibit automated retrieval).
- **Honesty rules** (in `src/lib/research/prompt.ts`): every figure cited with `[n]`, tagged with period and nature (reported / estimate / computed), "Not found" instead of guessing, web content treated as data not instructions, no price targets, a qualitative stance that is explicitly not a recommendation.
- **Streaming**: SSE route `/api/research/[exchange]/[symbol]` shows searches and page reads live, handles `pause_turn`, caches finished notes for 6 h, uses the refusal fallback, and reports token usage and cost. The finished note is saved in your browser and can be copied or downloaded as Markdown.
- **Credentials**: the SDK uses `ANTHROPIC_API_KEY`, or your `ant auth login` profile (active here). **Each note bills that account** (web research costs more than chat; the panel shows real token use). Every note is hard-capped at US$1.00 (`RESEARCH_MAX_RUN_USD`) and runs on Sonnet 5.5 by default (`RESEARCH_MODEL`); `RESEARCH_ENABLED=0` switches it off.
- **Cost-capped run (EMAAR, 18 Oct 2026)**: on Sonnet with the 1 USD ceiling, 8 searches and 4 page reads, 3,900 words, all 12 sections, 62 sources found, **$0.73** in tokens and search fees. **First live run (EMAAR, 17 Oct 2026, before the cap, on Opus)**: ~12 minutes, 8 searches and 8 page reads, ≈$1.67 in tokens (Opus 5.5), 27k-character note, 26 cited sources. Reviewed against the primary documents it cited: the H1-26 press release (revenue +21% to AED 23.9bn, EBITDA 12.9bn, attributable profit 8,670m, sales 26.6bn, backlog 164.9bn, land bank 590m sq ft), the ICD→Dubai Holding transfer (22.2723%, group c.29.73%) and the 16 Sep board decision (AED 4.4bn / 0.5 per share special dividend, subject to approval; "utilising various businesses" under review) all matched. Its own computed ratios (market cap, P/E, yield, turnover, EV/EBITDA) re-computed correctly. Not independently checked: the S&P rating PDF (scanned image) and third-party price pages.
- Issues the live run exposed and fixes: sections came out of order (§6 before §5) → `normaliseNote` re-sorts them and the prompt now says research first, write once in order; progress lines showed empty queries → tool inputs are now read from the block start as well as deltas, and "Analysing" lines collapse; the sources panel now separates the 26 cited from other search hits; the UI's time/cost estimate was wrong (said 2–6 min) → corrected.
- **Number of trades**: per-stock trade counts are not published free (only market-wide totals), so the analyst reports "not found" and gives labelled proxies (market-wide trades/value, the stock's share of turnover). A licensed exchange data feed would be needed for the real figure.
- **Two AI briefs per country** (country panel). **Country brief**: where the country stands, its economic indicators, current events and its engagement and relationship with the UAE, from headlines (including a UAE-angle news search), GDELT, hazards, WHO, sanctions, IMF and World Bank figures and the UAE agreements, trade, flights, investment and visits data. **Minister brief**: the same fact pack arranged for speaking (see above). Both use no web tools, so each costs about 2 to 4 cents (`BRIEF_MODEL`, default Sonnet 5.5), only run when you click, are cached for 3 hours, and show a warning once they are older than that. `BRIEF_MAX_PER_HOUR` (default 20) caps new country briefs and `BRIEF_ENABLED=0` switches them off. Every claim cites a fact id; uncited statements are marked as background. **News** in the country panel refreshes itself every 5 minutes while visible, with a separate list of coverage that names both the country and the UAE.
- **Detailed ministerial briefing** (Minister tab → "Open the briefing workspace"): a full-screen workspace that produces three linked documents for a UAE Minister of State: an executive brief (five minutes), a strategic country intelligence dossier (political, bilateral, economic, trade and investment, geopolitics and security, multilateral, development and soft power, consular, opportunities and risks) and meeting talking points (counterpart intelligence, tailored talking points, anticipated questions, negotiating and action matrix). You choose the counterpart (head of state to energy or defence official), meeting type, depth (executive, standard, comprehensive), focus areas and English or Arabic, and can paste desk input (approved UAE positions, previous meeting outcomes, objectives). It starts from this app's UAE-side record (agreements, missions, visits, trade series, IMF series, flights, investment, headlines, a dashboard of tiles drawn straight from the datasets) and researches the open web for what the datasets lack, citing every web claim with a link. The app holds no approved UAE positions, meeting minutes, consular data or negotiating mandates, so where the briefing needs them it writes `DESK INPUT REQUIRED` instead of guessing. Exports: a PDF file download (built in the browser from page images, so the text is not selectable; there is also a Print button), a Word-compatible .doc and a PowerPoint deck (one slide per section, built in the browser with pptxgenjs). It reads the web, so it costs more than the short briefs, but every run is **hard-capped at US$1.00** (`DOSSIER_MAX_RUN_USD`, never above 5): the output room shrinks as money is spent, and the stream is cut off the moment the running total passes the cap, with a note that the briefing is incomplete. It runs on Sonnet 5.5 by default (`DOSSIER_MODEL`; Opus costs about twice as much per token), at low reasoning effort for short runs and medium for long ones (`DOSSIER_EFFORT`), with a small search and page budget per length. Measured: a comprehensive ministerial briefing (8,300 words) cost $0.47 and an all-27-topics desk brief about $0.30 to $0.38. It only runs when you click, is cached for 6 hours and is capped per hour (`DOSSIER_MAX_PER_HOUR`, default 4; `DOSSIER_ENABLED=0`).
- **Desk brief** (own tab): a long political and economic analytical brief for a MoFA desk officer. The officer ticks the topics (27 across political, economic, relationship with the UAE and looking ahead, with Political, Economic, Joint and Everything presets, plus free-text extra subjects), and chooses the lens, the time horizon (30 days, 12 months, five years), the length (about 1,500 to 14,000 words), the style (bullets, prose, or full analysis with evidence tables), the language, and optional desk context. Output: Desk summary (key judgments, indicator dashboard, what changed), Analysis by topic, and Annexes (chronology, data tables, source assessment, gaps, watchlist). Same evidence rules, web research, caps and exports as the ministerial briefing; measured about $0.30 to $0.38 for an all-topics exhaustive run (about 6,500 words); the length options are 1,500, 4,000, 6,000 and up to 10,000 words.
- **Intel tab** (country panel): the indicators that make a brief stand out, all deterministic and free of AI cost. **Leverage and exposure** (how far each side leans on the other: UAE share of the partner's trade and investment against its share of UAE trade and investment, as percentiles on a quadrant), **Bilateral temperature** (GDELT events between UAE and the country on the Goldstein scale, weekly line, cooperation vs conflict share), **Governance and stability** (World Bank governance scores with the UAE marked), **Leadership clock** (head of state and government, tenure, age, coming elections from Wikipedia calendars), **UAE investment and deals** (IMF investment position plus UAE company and fund deals read from WAM headlines, each linked), **UAE humanitarian funding** (OCHA FTS, by year), **Since your last read** (what changed since you last opened the country, stored in your browser, with Mark as read) and **Triggers** (editable rules checked on open, such as bilateral temperature below a threshold, a cooling trend, a gap since the last senior engagement, new sanctions entries). The same indicators are facts in the country brief, the minister brief, the detailed ministerial briefing and the desk brief. Sources and limits are stated on each card; datasets: `governance.json` (monthly), `leaders.json` (monthly), `uae-aid.json` (monthly), `leverage.json` and `deals.json` (daily, with the data refresh), `temperature.json` (daily, with the media-tone refresh).
- **Country scorecard and rivals** (top of the Intel tab; `scripts/build-scorecard.mjs`, `scripts/build-rivals.mjs`): the scorecard rates every country on eleven aspects in three groups. The relationship: political friends 14%, business friends 12%, strategic value to the UAE 9%, UAE leverage 12%. The country: political stability and capacity 8%, economic 8%, financial 7%, social and people-to-people 5%, security and risk 7%. Weight in the world: UN influence 8%, global influence 10%. Every part is a 0 to 100 percentile among countries with data (or a yes/no flag such as a Security Council seat or OPEC membership), so nothing is judged against an invented standard; a dimension is the mean of its parts and the overall score the weighted mean of the dimensions that have data, with coverage shown. Strategic value is a heuristic, and the social aspect covers connectivity and openness only. "Who else is here" compares the UAE's share of the country's goods trade with China, the US, India, Türkiye, Saudi Arabia, Qatar, Russia, Germany, France, Italy, the UK, Japan and South Korea (IMF customs data against World Bank totals; mirror data, trade weight only). Both feed every brief as cited facts.
- **Cost** (cold runs, measured on Egypt, Oct 2026, with the web research actually working; every run is capped at US$1): country brief about $0.05, prep pack $0.06 (Economy mode, a checkbox on both, uses a smaller model for about $0.013 and $0.02), Leader's brief $0.11, counterpart profile $0.22, investment dossier $0.24, standard ministerial briefing $0.32, short desk brief about $0.19, detailed desk brief about $0.40. What keeps them down: Sonnet at low effort; a search budget per product spent on named targets (last 30 days, rival footprint, next 90 days) with a minimum use; no page-fetch tool where it was never used; the paused search loop resumes in the same code container and is told which searches already ran; search code prints only what it needs; real word ceilings; and a lean system prompt per audience. Tried and rejected: the basic web-search tool (dearer) and a smaller model for the long briefs (it skipped the research).
- **Research reliability** (a lesson, kept in the prompts and the route): the search tool is driven by code the model writes, and that code failed silently in many runs while the searches were still billed. Causes found and fixed: telling the model to run all its searches in one code block (one error, or touching the tool limit, killed every search), so it now searches one query per step and never retries; the result shape ("rows = json.loads(await web_search({...}))", a list of dicts with title, url and content), which the prompts now spell out; and a margin of four above the stated budget on the tool limit. The route logs every failed research step, tells the user, and the briefs must open with a one-line research note when research failed. When comparing costs, check that the brief cites web sources: a cheap run with no links is a run whose research failed.
- **Illustrated view** (an optional second part of every brief: the Illustrated tab in the briefing workspace and a Read / Illustrated switch on the country brief and the prep pack): the score ring and an eleven-axis radar, the three group bars, stat tiles, the leverage quadrant, the rivals bars and the weekly tone line from the data, plus the bottom line, key judgments on a likelihood meter with confidence dots, the play as numbered steps with instrument tags and timing, gives and asks, warning signs and decisions, read from the text of the brief. It makes no model call, so it costs nothing extra.
- **Statecraft lens** (`src/lib/statecraft.ts`): one realist framework shared by the country brief, the ministerial prep pack, the detailed ministerial briefing and the desk brief. Seven instruments of influence (hard, economic, financial, logistic, soft, humanitarian, diplomatic) tag every proposed move; the briefs map the UAE's hand against the counterpart's and the rivals', give three courses of action with second-order effects, a sequenced play with timing windows, a gives, gets and holds-back table, a red team with tripwires and a concession ladder. Realism is the method, not licence: every move must be lawful, evidence-bound, labelled a proposal and never stated as UAE policy. The detailed briefings are told to spend their search budget on the last 30 days, on rival footprint and on the next 90 days of scheduled events, and to put the newest source's date in the as-of line.
- **The three advisers** (`src/lib/advisers.ts`, in the ministerial briefing, the Leader's brief and the investment dossier): the National Security Adviser, the Minister of Economy and the Minister of Foreign Affairs each read the same facts with their own questions (threat, exposed nodes, red lines, pre-mortem; interest in numbers, stranded-capital risk, structures and protections; coalitions, linkage, deliverables, what other capitals read into it), then a mandatory reconciliation says which lens should lead and gives one recommended course. The ministerial brief opens with a three-row reading and a reconciled call, requires judgments from all three lenses, and tags every negotiating-matrix row security, economic or diplomatic.
- **UAE investments tab** (`src/components/InvestTab.tsx`, `src/lib/invest-data.ts`, `/api/invest/[iso3]`): the IMF position series in both directions (mirror data; a gap such as Egypt's is stated, not hidden), every UAE company and fund deal found in WAM headlines with filters by investor and sector and a quarterly timeline, who is active, the protection toolkit (investment and tax treaties, CEPA, joint committee), risk context (World Bank governance and the IMF outlook) and plain read-out flags. A click-started **Investment dossier** (about $0.24, `src/lib/dossier/investments.ts`) adds the researched register: five kinds of UAE money kept apart (sovereign equity, state-company assets, private, state-to-state money, pledges), status words that never turn an announcement into a completed deal, flagship assets, deposits and loans, exposure through the three advisers, concentration and sovereign risk, protection gaps, competing capital and recommended moves. Wikidata was tried as a holdings source and dropped: its coverage of UAE-owned assets is too thin and its query service times out.
- **Foresight: two products from one evidence base** (`src/lib/dossier/foresight.ts`, `src/lib/foresight.ts`, `src/lib/uae-advantage.ts`, tab in `src/components/ForesightTab.tsx`). Benchmarked to Global Trends 2040 (forces, dynamics, uncertainties, scenarios that are not predictions), the 2012 and 2026 Annual Threat Assessments, the 2021 Intelligence Community Assessment, a 1965 President's Daily Brief, the UK Global Strategic Trends and the UK Futures Toolkit. Both products share the same facts, the same method block (projection, forecast and scenario kept apart, base rates, falling confidence with distance, pre-mortem, backcasting) and the **UAE-first mandate**: ten questions, fifteen impact areas, eight kinds of advantage each tested for realism, options kept apart from judgments, scores labelled dataset or analyst judgment, independence, and a silent quality gate. They are prioritised separately, so the brief is not a cut-down of the report. **Ministerial Executive Brief** (about $0.21 measured on Egypt, about 2,800 words): eight pages (snapshot with a large-number dashboard; what is changing with a timeline; forecast path, IMF path and scenarios; UAE impact matrix; opportunity radar; options by window of 0 to 12 months, 1 to 5 years and 5 to 20 years; risk heat map with warning thresholds; bottom line with decision, action, deadline and cost), drawn as designed pages from the text with no further model call. **Comprehensive Strategic Report** (about $0.47 measured on Egypt, about 8,250 words with ten searches allowed): sixteen sections in four parts over horizons of 1, 3, 5, 10 and 20 years, with forecast ranges, weak signals, interdependencies, impact matrix, opportunity map, options and a three-adviser reconciled call, risk matrix, signposts, comparative scores and annexes; its Illustrated tab adds the data baseline, a front-by-horizon heat grid and a risk heat map. About 30 to 40 printed pages with the visuals: a 100-page report would need a multi-stage run costing over the dollar ceiling. **Free parts, no model call:** the baseline board (IMF path to 2031, tenure, election calendar, governance, sanctions, investor protection, relationship momentum), the UAE impact graph (ten spokes from the scorecard percentiles; dashed where no dataset exists), a scenario-weight simulator that re-ranks opportunities by the share of weight in which each still works (not a probability of success), a follow-up tracker kept in the browser (status, due date, note), a changes-since-the-previous-report panel, and Print pages (PDF) for the illustrated pages. A free-text focus subject (an oil-price collapse, Red Sea shipping, a trade agreement) steers either product. Not built: global, regional and sector reports with no country (they need their own data pipeline). Research is the weak point, as with the other briefs: in the Egypt runs two to three searches timed out inside the code step, the products said so in their research note, and thin sections were marked not found after searching, so check the note and the cited links.
- **Falcon Eye** (a top-level tab beside World and Markets, `/falcon`; `src/components/falcon/`, `src/lib/falcon/`): the intelligence console of Geo Desk, built to the THE FALCON specification as far as the app honestly can. One shared world model and one set of saved products feed ten sections: **Command Center** (counts, a live situation room from the merged alert feed with category, severity and UAE filters and the answer state of each source, the early warnings with the biggest UAE stake, and the build date and freshness of all 20 datasets: current within 1.5 refresh cadences, due within 3, stale beyond; two GDELT datasets are stale at the time of writing and the page says so), **Radar** (every country scored on opportunity and risk from transparent parts, each with its source and a slider: the scores, a scatter of risk against opportunity sized by the UAE's stake, three ranked lists and a full early-warning board whose indicators each have a written threshold, baseline, source, frequency and UAE impact; scores place countries against each other, they are not predictions), **Country Desk** (scores, triggers, the four briefing products, and the Foresight baseline, impact graph and tracker), **Foresight** (the two foresight products), **Scenario Lab**, **Council**, **Graph**, **Monitor**, **Library** and **Platform**. The **Scenario and Policy Lab** (measured on Egypt: about $0.36 standard, $0.52 deep; the deep lab adds typed and sourced causal links, tipping points, historical analogues, outside reference scenarios, a latest-developments check and regret analysis across the three variants) traces a shock or policy question through an outcome graph of direct, second and third-order outcomes with converging paths, compares mild, central and severe variants, maps UAE exposure and scores options (the baseline and waiting always included) on six criteria; the Illustrated tab draws the graph and an options analyzer whose weights you move, with a robustness check (the share of 400 random weight sets in which each option ranks first). Plausibility bands are never presented as probabilities. The **Red Team** (about $0.16) reviews any saved product independently: verdict, strongest competing explanation, competing hypotheses, judgments to change, omitted actors, checks of figures and dates against sources, premortem; the reviewed text is treated as data, never instructions. The **Library** keeps every product generated on this browser (open, red-team, delete) and a **forecast registry**: key judgments with a likelihood band, frozen at issue, which you mark true or false so it can report a Brier score and skill against always saying roughly even (coarse: band midpoints stand in for probabilities, and it warns below 20 resolved). The **Platform** page lists the GEO BRIEF register GB01 to GB20 with an honest status each (live, partial, roadmap), the five reference reports in a method register with the pages read, and what is not built: multi-agent services, a knowledge-graph database, ingestion with licensing controls, sign-in and approval gates, continuous monitoring, claim-level evidence storage, and global or region-only products. Bilingual (Arabic RTL checked). All AI products now go through one product resolver (`src/lib/dossier/products.ts`), so a new product is one entry.

- **Deployment note for the AI routes**: the hourly caps, caches and in-flight guards live in the memory of one server process. That is right for `next dev`, `next start` or a single container; on serverless or several instances each instance has its own cap and cache, so put a shared store in front before exposing them. The AI routes accept only same-origin JSON requests, but they have no sign-in: do not expose them to an untrusted network without adding authentication. Each detailed briefing is also bounded by a per-run cost ceiling (`DOSSIER_MAX_RUN_USD`, default 6) and at most two run at once.

## Not built or not live
See `docs/parity.md` (generated by `npm run parity`) for the current list and the reason for each. - REST Countries' public API is deprecated, so country basics come from World Bank + Wikidata at build time.

- Arabic mode translates the UI and country names; region, language and capital names stay English (source data).
